## 中文

Gradle 1.0.0 是面向当前 Viva preview 的预发布，提供 Gradle 项目模型、构建任务、JavaExec 应用、筛选测试、编译诊断和依赖树。

### 升级与兼容性

相对 0.1.2，本版迁移到插件契约/API/能力版本 0，旧 macOS Lithe 和旧协议宿主无法安装，因而使用主版本 1.0.0。升级前请使用包含 [Lithe #1884](https://github.com/1lck/Lithe-IDEA/pull/1884) 的 Viva 客户端（修订 `607f00967d70a7017d49805183d0d2e6ffdf1c0d` 或更新）以及 Java Support 1.1.0。项目文件和设置键不需要迁移。

需要 Gradle 7.6+（项目 Wrapper、GRADLE_HOME 或 PATH）及该 Gradle 版本支持的 Java；插件后端兼容 Java 8，不附带 Gradle。ZIP 不带发布者签名，在客户端插件设置中从文件安装；`darwin.zip` 和 `windows.zip` 内容完全相同。

### 更新

- 修复当前 Viva 的后端启动与实际 Gradle 导入配置读取，CLI 构建成功不再掩盖设置后端失败。
- gradle.properties 按 Gradle 官方规则应用用户级优先级，缺失文件正常继续，损坏、不可读或超过 256 KiB 的配置明确失败；读取不写回用户配置。
- 配置后端显式设置 Xms16m/Xmx128m；控制试验 RSS 中位数约 46→44 MiB，响应时间没有显著变化，不代表整套 Java 支持内存下降。
- 固定官方 Java SDK 与许可证，收紧测试驱动缓冲，并验证 Windows 进程清理。

macOS/Windows 无头验证包含 Gradle 7.6.4 Wrapper 双模块、中文空格目录、真实配置回读、编译、补全、运行、断点变量、继续/停止与插件目录只读。原生窗口、任意 Gradle 生态和全部日志/取消路径未完整验收。JavaCC、多版本 JAR、部分旧泛型代码等 Java 语言服务限制仍存在。

## English

Gradle 1.0.0 is a prerelease for the current Viva preview, providing project models, build tasks, JavaExec applications, filtered tests, compiler diagnostics and dependency trees.

### Upgrade and compatibility

This release migrates from 0.1.2 to contract/API/capability version 0. Legacy macOS Lithe and old-protocol hosts cannot install it, which requires the major version 1.0.0. Upgrade to a Viva client including [Lithe #1884](https://github.com/1lck/Lithe-IDEA/pull/1884), revision `607f00967d70a7017d49805183d0d2e6ffdf1c0d` or newer, and Java Support 1.1.0 first. Project files and setting keys require no migration.

Supply Gradle 7.6+ through the project wrapper, GRADLE_HOME or PATH, and a compatible JDK. The backend supports Java 8; Gradle is not bundled. Install the unsigned ZIP from a file in plugin settings; `darwin.zip` and `windows.zip` contain identical bytes.

### Changes

- Fixed Viva backend startup and actual Gradle import-setting reads; successful CLI builds no longer conceal a failed settings backend.
- Apply user-level gradle.properties precedence according to Gradle rules. Missing files are optional; malformed, unreadable or over-256-KiB files fail explicitly. Reads never write configuration.
- Set the configuration backend heap to Xms16m/Xmx128m. Controlled median RSS was about 46→44 MiB with no significant latency change; this is not a reduction for the entire Java stack.
- Pin the official Java SDK and license, bound test-driver buffers and verify Windows process cleanup.

Headless macOS/Windows validation covers a Gradle 7.6.4 wrapper reactor, Unicode/space paths, actual setting readback, compilation, completion, execution, breakpoint locals, continue/stop and read-only packages. Native windows, arbitrary Gradle ecosystems and every logging/cancellation path are not fully accepted. JavaCC, multi-release JARs and some older generic code remain language-service limitations.
