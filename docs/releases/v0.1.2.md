0.1.2 自 0.1.1 以来的变化：

- 移除宿主已删除的 `buildSystems.languageImport` 清单字段（新版 Core 严格校验会拒绝它）；改为导出插件函数 `languageImport.settings`，由插件后端向 Java Support 提供 Gradle 导入设置（离线开关、Gradle 用户目录）。
- 插件后端改用 Java（`lib/lithe-gradle-backend.jar`，直接编译 `vendor/` 下官方 Java SDK 源码并逐文件校验），与 Maven 插件结构一致；安装包附带 SDK 许可证。
- 接手 Java Support 的 Gradle 新建项目入口：新增 Gradle 项目生成器（Kotlin / Groovy DSL）及项目模板（`projectGenerators`）。
- 清单新增 `backend: 2`、`pluginFunctions: 1`、`projectGenerators: 1`、`serverProcess: 1` 要求，权限新增 `backend.launch`、`project.generate`、`workspace.metadata`。

兼容性：
- 稳定版 Lithe 0.6.7 没有 `pluginFunctions 1`，会拒绝安装本版本；Store 条目逐项复制 `requires`，让稳定版继续选择 0.1.1。0.1.1 仍声明 `languageImport`，新版 Core 不再接受，需要升级到 0.1.2。
- 本版本不再声明 `languageImport`。仍读取该字段的旧宿主（例如 0.6.7）在启用 0.1.2 后无法把 Gradle 设置带入 Java 导入。
