# Gradle 2.0.1

## 中文

- 打开 Gradle 项目的 Java 启动类后，可以从工具栏直接运行或调试。Gradle 会编译该文件所属的源集，并使用该模块的运行时依赖。
- 可以把当前文件的启动入口保存为 Gradle 应用配置，供之后运行或调试。
- 修复部分严格校验项目属性的 Gradle 工程无法导入的问题。

### 兼容性

此版本需要支持 `buildSystems: 2` 和 `buildProviders: 1` 的 Lithe 桌面端。请先升级桌面端，调试 Java 应用时还需安装 Java Support。Lithe 0.8.12 可继续使用 Gradle 2.0.0。

---

## English

- Open a Java entry point in a Gradle project and run or debug it from the toolbar. Gradle compiles the file's source set and supplies the module's runtime dependencies.
- Save the current file's entry point as a Gradle application configuration to run or debug it again later.
- Fix project import for Gradle builds that strictly validate project properties.

### Compatibility

This release requires a Lithe desktop host that supports `buildSystems: 2` and `buildProviders: 1`. Upgrade Lithe and install Java Support to debug Java applications. Lithe 0.8.12 can keep using Gradle 2.0.0.
